4. Home Page Layout

Current Structure

Current Layout:

  • Title + subtitle
  • Search bar (inside filter panel)
  • Big filter panel (logged-in only)
  • 4-column listing grid
  • Text-based cards
✓ Clean and organized
✗ Filters take up space
✗ Search hidden for anon users
✗ Cards feel secondary to text

Modern Structure

Proposed Improvements:

  • Hero search bar (prominent, always visible)
  • Collapsible filter sidebar (not full panel)
  • Image-dominant 3-column grid on tablet, 4 on desktop
  • Sticky header with search
  • Category chips for quick filtering
  • Trending/Featured section
✓ Search is hero element
✓ Filters don't dominate
✓ Better on mobile
✓ More discoverable
✓ Trending builds urgency

Summary of Modern Improvements

  • ✓ Image-first design: 1:1 square images instead of 4:3 (more eye-catching)
  • ✓ Seller trust: Avatar + rating visible on cards (builds confidence)
  • ✓ Urgency signals: "NEW", "TRENDING" badges (drives action)
  • ✓ Dark mode: Respects user preference (modern expectation)
  • ✓ Shimmer skeletons: Premium loading experience
  • ✓ Better spacing: More breathing room between elements
  • ✓ Micro-interactions: Smooth transitions, hover effects
  • ✓ Sidebar filters: Less clutter, easier to use
